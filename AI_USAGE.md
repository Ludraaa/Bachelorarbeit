# AI Usage Statement

AI tools were used in a restrictive and assistive manner during the development of the software accompanying this bachelor's thesis.

AI assistance was mainly used for implementation, debugging, refactoring, and other development tasks. The design and overall approach of the implemented components, as well as the scientific reasoning and evaluation, were carried out by me.

AI assistance was used for the following tasks:

* parts of the linker and knowledge base modules,
* file metadata infrastructure,
* debug logging infrastructure,
* plotting and visualization of evaluation results,
* selected refactoring and code organization,
* development of the result explorer website,
* Makefile and Dockerfile infrastructure.

AI-generated code was reviewed, adapted, and tested by me before being included in the repository. AI was not used to carry out the scientific analysis or to interpret the experimental results.

I am responsible for the final code and the contents of the thesis.
